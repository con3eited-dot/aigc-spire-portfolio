# AIGC分段素材剪辑与交付

把实际生成结果剪成可观看的视频，保留指定版本与关键剧情。剪辑依据是素材中的画面和声音；提示词只说明创作意图。只有项目通过真实打开、播放和导出，才能报告剪映兼容性通过。

## 先确定剪什么

确认输入顺序、版本、必须保留的动作和结尾、输出位置及用户是否要求剪映工程。原文件保持原样，输出使用新文件名。不要用另一版素材修补用户明确选定的版本，除非已获授权。

读取每段视频的尺寸、显示时间戳、实际帧率、视频时长和音轨时长。VFR素材的容器时长、名义帧率、解码帧数可能不一致；依据时间戳统一时间基，不把“60fps”头信息当作播放速度。查看每段开头、结尾及两个接缝附近的实际帧；能试听时检查原声，不能试听时明确记录这个限制。

## 把接缝做成具体切点

为每个接缝写明：前段出点、后段入点、两侧姿态、运动方向、景别、光色、声音处理，以及转场实际时长。地点改变可以直接切镜；同一动作才做动作匹配。短片最后的笑点、攻击意图和反应特写按用户要求保留。

| 实际画面 | 可选处理 |
|---|---|
| 塔外迈步 → 塔内开箱 | 清楚的叙事切换，直接切镜；短音频淡化避免切口爆音 |
| 追逐末尾确有金色闪光 → 崖底暖光 | 先尝试直接切；需要时极短地延续已有暖光，随后恢复洞穴光线 |
| 前片没有明显闪光 | 不套用闪白方案；按姿态、运动或地点变化重新选切点 |
| 角色造型或位置不匹配 | 避免长叠化叠出双重身体；保留明确的空间建立画面 |

这些是按素材选择的办法，不是每次都要添加的特效。过渡不能遮掉原片的重要动作。声音只有混合音轨时，仅描述实际完成的整体音量和淡化；不能声称已独立保留脚步、移除配乐或重做怪物声。

## 执行与声音

用户指定剪映时，先验证独立测试草稿能真实打开和播放。不要改正在运行的软件所写入的草稿列表或项目。窗口捕获持续失败时保留证据、说明障碍；若用户已授权制作通用视频预览，可用本地FFmpeg输出MP4，交付时明确工具差异。只要求剪映工程时，MP4不能冒充剪映工程。

FFmpeg剪辑按[编码与验证参考](references/ffmpeg-editing.md)执行。统一帧率、像素格式和时间基；分别重置音画时间戳，并把每段音画明确裁到同一已确认长度后再拼接。不要只在方案中写“对齐”，却让实际命令按不同音画时长自动补帧。

音量可以先测 integrated LUFS 和 true peak，再决定增益。选定响度目标后计算所需增益，并按峰值余量限制它；保留原声的叙事动态。目标响度不是每个项目固定-20LUFS。淡入淡出的起止必须落在实际保留的片段内部；结尾突然结束时只做必要的防爆音处理，不强加长淡出。

## 验证后交付

完整解码成片，核对实际视频帧数、时长、音轨长度与同步；重看接缝前后及最后一秒，检查意外黑帧、停帧、双重角色和声音突变。黑场检测要区分有意转场与意外错误。复测输出响度与峰值，不能只引用输入测量或编码成功。

交付至少说明：所用版本、输出链接或路径、实际时长与规格、两个切点的理由、已执行的检查、未试听/未验证事项。剪映工程另报三种状态：结构检查、实际打开播放、实际导出；它们不能相互替代。若附独立草稿，检查路径、素材引用与时间线，并注明效果是否已烘焙到中间素材、是否仍可单独调整。
