# 输出导演调度与分镜提示词

把故事转成生成模型可执行的动作关系。对工具实际支持的参考图、视频、音频和时长先核实；工具能力不确定时写成制作意图，不承诺模型一定执行。

## 参考和约束账本

区分四种用途：身份图锁角色；设定图锁细节；白模或动作视频锁路线、调度和时机；其他成片只供创作者分析。只有实际上传给生成平台的文件才能在最终提示词中绑定。不要把“给助手看的观察视频”误写成模型的参考对象，不虚构锚点编号。

先整理当前有效要求：总时长与画幅、角色和道具数量、外观锚点、世界与画风、动作节点、运镜、声音、硬限制。用户后来的明确修改替换旧要求；例如环境已经改成尖塔内部，就清除残留冰封城市、冰爪和风雪设定。矛盾约束先指出并解决，不能在同一文本里同时许诺互斥动作。

## 成稿顺序

用 [导演文本结构](references/director-template.md) 写成一份文本：核心声明 → 参考绑定 → 角色与性格 → 空间布局 → 色调、材质、照明 → 摄影规则 → 按时间分镜 → 声音与台词 → 连续硬规则。即使要求少换行，也保留短标签帮助模型分段理解。

分镜时段要完整覆盖总时长，不重叠、不留空。每镜一个核心动作、一种主运镜；复杂过程拆成明确连续阶段。写出起始姿态、动作接触点和结束状态。白模已限定的大动作、起身节奏、追逐方向和跳跃时机不另行重排；新增攻击或道具特写放在允许插入的窗口中，不让角色同时执行多个不可能动作。

如果不能查看白模且没有可靠时间码，先交付明确标为“约束稿”的文本，列出待核实的动作窗口；不编造已匹配参考的精确分镜，也不声称新增动作一定容得下。取得实际参考后再定时。

## 空间不能只写“同向”

建立固定世界路线和地标，说明谁在前、谁在后、相对距离和视线；运镜改变画面方向时保留世界前进方向。独立飞行的道具也有连续轨迹，不能和追赶者变成迎面而来。角色、道具、墙面和深渊分层清楚，接触、分离、起身和着地都有可追踪过程。

需要强解封感时写“墙内轮廓与脉冲→裂纹与外鼓→肢体突破→碎壳脱落→完整现身→锁定追击”，不能只写怪物已站在墙前起跑。需要遗物挣脱时写“拿稳→轻微晃动与微光→脱离手掌→独立同向飞行”，保持因果顺序。

## 风格与声音

配色、材料粗糙度、布料厚度、环境层次、体积光与景深要具体且相互协调。摄影采用稳定跟拍还是自然呼吸手持，由当前要求决定，不同时要求稳定无晃动和全程手持。若指定禁止90°纯侧面，镜头使用可执行的斜侧或三分之四角度；不要把此限制套用到人设正交三视图。

声明有无对白、旁白、音乐、字幕及允许的界面文字；动作音效对齐接触时机，关键声源有空间方位。不能在“无文字”之后又毫无解释地要求意图数值；例如只允许红色菜刀图标与“8x3”，其余字幕和UI关闭。

## 长度和交付

用户指定4000字以内时，以最终复制文本的字符数为上限，标点、空格、换行都计入。先压缩换行、重复形容词与重复规则，再缩短低价值描述；保留参考、数量、空间、动作因果、时间与声音限制。实际计数后交付，不用肉眼估算，也不为凑满上限添加噪声。

生成提示词不等于生成视频。审阅成片后分别报告已实现、未实现和下一轮修改，不把提示词中的期望写成成片事实。
