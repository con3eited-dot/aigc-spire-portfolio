# 导演文本结构

以下是填实信息的结构，不是要求模型照搬的占位符文本。

【核心声明】时长、比例、媒介与题材；所有大动作跟随实际上传的白模参考；仅升级当前授权的美术、角色和环境细节。
【参考锚定】列实际附件及用途，分别绑定主角、两只追兵、遗物、动作路线。仅供助手观察的成片不出现在附件绑定中。
【角色资产与性格】不可变外形、色彩、数量；用姿态和电子音表达机械角色的情绪。
【空间布局】开场位置、封印墙位置、逃亡路径、裂口位置；四个主体的世界方向、前后距离和终点。镜头切换不改变空间关系。
【视觉与摄影】统一配色、材质、光影和环境纵深；明确稳定或手持风格；主体清晰，特效不遮蔽动作关系。
【分镜】逐段写“起始状态→一个核心动作→结束状态；景别、角度与一个主运镜；对应声音”。道具特写前后接续同一条世界轨迹。
【声音与台词】声源、同步点、音乐动态、对白与字幕规则。
【硬规则】角色数量与身份固定，轨迹可追踪，不穿模、不复制、不瞬移；遵守实际指定的机位和文字限制。

空间句的示范：“沿石桥尽头的拱门持续前进；冰淇淋领先鸡煲约一个身位，两只咔咔在鸡煲左后、右后错开追赶。摄影机沿路线后退拍摄时，四者都朝拱门前进，不能让冰淇淋朝镜头飞走而其余角色向反方向跑。”

五秒片段通常只容纳少量清楚动作；十五秒也不应堆入开箱、解封、反复战斗、多个跳跃及完整结局。动作预算以实际参考和时间为准。
