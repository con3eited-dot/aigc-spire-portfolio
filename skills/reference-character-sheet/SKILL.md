# 从参考素材生成人设图

把已有造型转成可重复使用的视觉资产。默认交付可复制提示词；只有用户要求实际出图且图像工具可用时才调用生成工具。

## 先锁定什么

实际查看用户提供的图片；视频不能查看时说明限制。按用途区分身份参考、造型细节、画风参考、姿态参考。用户没有提供给生成平台的素材，不能写成平台已知的参考图。附件编号或平台锚点以真实上传顺序为准，不虚构 `@图片1`。

提取身份锚点：轮廓与头身比、面部或传感器布局、主辅色、衣物结构、肢体与道具数量、连接位置、材质和具有辨识度的破损。把可见事实与新设计分开；被遮住的背面细节采取最小延展，并标为推定，不能冒充官方设定。

## 提示词结构

依次写：参考图绑定 → 角色身份与性格气质 → 不可变的外形锚点 → 色调与材质 → 视图和画面布局 → 姿态与照明 → 排除项。完成文本应能整段复制到生成平台，不夹带使用说明或工具能力承诺。

四宫格三视图默认是正面、严格侧面、背面三个全身正交视图，加一个三分之四角度细节图；写清每格位置。全身三视图同高度、同尺度、同基线、同中性姿态，头脚完整，避免透视缩短。用户要求 9:16 时，约束整张画布为 9:16，而不是声称四个子格各为 9:16。需要动作资产时，细节格也可改为用户指定的动作格。

三视图的严格侧面是测量视图，不能机械套用视频里的“禁止纯侧面90°构图”。电影CG、二维动漫、稳定机位或其他风格按当前任务选择；不把某次项目的风格变成所有人设图的固定要求。

## 本项目的锚点示例

- 鸡煲：旧金色机械头壳；上小下大的两个青蓝圆形部件；青蓝胸部核心；蓝色披布；纤细机械四肢。靠姿态和机械部件表达情绪，不增添人类五官。
- 黄色闪电球是特定剧情中的外部能量球，不要把鸡煲本身的青蓝传感器和胸核一并改黄。
- 冰淇淋是道具：上层粉色、中层巧克力棕、下层浅奶油色，浅黄甜筒；不因“人物提示词”的叫法自动加手脚或脸。

## 检查

交付前核对每格是否同一角色，锚点、配色和数量有无冲突，是否把参考图中看不到的部分写成事实。仅写了提示词时说明这是提示词；真正看过生成结果后才评价人设图是否一致。需要可复制结构时读 [输出范式](references/output-template.md)。
